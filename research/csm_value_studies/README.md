# CSM Value supporting studies

Run `python3 research/csm_value_studies/position_count_study.py` to compare maximum position counts, or `python3 research/csm_value_studies/train_test_protocol.py` for the historical profit-definition comparison. Results are saved in this folder's `output/`.

These studies use the current CSM Value runner and the temporary 31 December 2024 data boundary. The later comparison period has been examined before and is not a blind test.
