# Archived CSM Value files

These files were moved out of `csm_value/` to make the active strategy easier to navigate. No historical output or script was deleted. `output/` contains the previous saved run, including its trade and daily logs; those results may include dates after 2024 and may use superseded assumptions.

`HISTORICAL_README.md` was reconstructed from the tracked README and the previously observed uncommitted additions after the moved README was accidentally overwritten while creating this index. It may not be byte-for-byte identical to the prior working copy.

The archived scripts and the original README/AUDIT documents are snapshots. Their relative paths and assumptions refer to their former location and they should not be treated as current executable research or as current performance results. The active CSM Value files are in `../../csm_value/`; current research studies are under `../csm_value_studies/` and `../csm_value_live_signals/`.
